# SpecLabel

The boxed drawing title for diagrams, simulators and saved designs: sheet code, title, then qualifiers.

**Consumer provides:** a sheet code (`B-` blueprint/lesson figure, `S-` simulator, `D-` design, `C-` case study, plus a number), a title, and 0–2 qualifiers such as `NTS` (not to scale), `LIVE` or a scale.

- 1.5px `ink` box; the code cell is inverted (`ink` fill, `paper` text, 600); cells divided by 1px `ink`.
- `mono-caption` uppercase. The last qualifier may be `ink-muted`.
- Place top-left of a canvas or figure frame, or in a simulator header as its title.
- Don't: put long sentences in it or use it as a button.
